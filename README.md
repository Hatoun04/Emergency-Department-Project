# Predicting Emergency Department Demand

This project analyzes emergency department (ED) visits and builds forecasting models 
to identify high-demand periods. The results aim to **improve staffing, reduce wait times, 
and optimize hospital resource allocation**.

---

## Dataset
- Source: [https://www.kaggle.com/datasets/rivalytics/er-wait-time?utm_source=chatgpt.com&select=ER+Wait+Time+Dataset.csv]
- Contains daily ED visit records with features such as date, time, and patient volume.  
- Preprocessing includes handling missing values and normalizing time series data.  

---


## 🚀 Installation & Usage
Clone the repository and install dependencies:

```bash

cd Emergency-Department-Project
pip install -r requirements.txt
```
